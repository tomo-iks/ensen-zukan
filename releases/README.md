# 沿線まち図鑑 Android アプリ

## ダウンロード
- [ensen-zukan-debug.apk](ensen-zukan-debug.apk)（約57MB・デバッグ版）

## インストール(Android)
1. スマホで上のファイルをダウンロードして開く
2. 「提供元不明のアプリ」の許可を求められたら、許可する
3. インストール後に開き、お散歩を始めるとき、位置情報(「常に許可」または「アプリの使用中のみ」)と通知を許可する

## できること
- お散歩の経路を、**画面を消しても**記録する(通知に「お散歩を記録しています」と出ます)
- 経路を、地図の道に合わせて補正する
- 気分から街を選ぶ、行った・ピン・お散歩の記録

## 注意
- 配布用の署名をしていないデバッグ版です。Google Play には登録していません
- iOS 版はありません
